# Guía de uso de Rift Sanctum

1. Abrí **Mi santuario** para ver el perfil original de referencia.
2. En **Tu santuario**, ingresá un Riot ID completo de LAS como `KillerBiss#2013` y pulsá Buscar. El historial muestra hasta cinco partidas públicas.
3. Explorá los emblemas de rango y maestría y abrí Personalizar perfil. Los cambios de apariencia se guardan en este navegador y no modifican la cuenta de Riot.

4. En el **Perfil de ejemplo**, debajo del historial, abrí una partida para ver el marcador y la cronología. Elegí cola y período y cargá más resultados para ampliar el análisis de rendimiento.
5. En **Maestrías** podés buscar un campeón y consultar sus hitos. **Progreso** guarda una observación diaria en este navegador al abrir la pestaña. El perfil de ejemplo permite probar el recorrido mientras se tramita el acceso público.
